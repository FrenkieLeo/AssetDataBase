# 聊天维护约定

之后通过聊天维护资产时，资产主档一律按照盘点册原表字段更新：

`序号`、`资产编号`、`资产名称`、`规格型号`、`资产类别`、`权属单位`、`现使用单位`、`购置日期`、`账面原值`、`账面净值`、`使用部门`、`存放地点`、`使用人`、`资产现状`、`原固定资产编码`、`盘点情况`。

## 新增资产

建议提供：

- 资产编号
- 资产名称
- 规格型号
- 资产类别
- 权属单位
- 现使用单位
- 购置日期
- 账面原值
- 账面净值
- 使用部门
- 存放地点
- 使用人
- 资产现状
- 原固定资产编码
- 盘点情况

示例：

```text
新增一台资产：资产编号 SY020101052999，资产名称 台式电脑，规格型号 联想 开天 M90h，资产类别 计算机，权属单位 广州交投实业有限公司，现使用单位 广州交投实业有限公司，购置日期 2026年7月24日，账面原值 4787.61，账面净值 4787.61，使用部门 综合管理部，存放地点 9楼办公室，使用人 张三，资产现状 在用。
```

我会执行：

- 在 `data/assets.csv` 按原表字段新增一行
- `序号` 自动顺延
- 在 `data/asset_events.csv` 追加 `purchase` 或 `register` 事件

## 调拨资产

建议提供：

- 资产编号
- 原使用部门、原存放地点、原使用人
- 新使用部门、新存放地点、新使用人
- 生效日期
- 经办人或审批依据

示例：

```text
把资产编号 SY020101052405 从安全监管部陈文初调拨给综合管理部李四，存放地点改为 9楼办公室，今天生效，经办人王五。
```

我会执行：

- 更新 `使用部门`
- 更新 `存放地点`
- 更新 `使用人`
- 必要时更新 `现使用单位`
- 在 `data/asset_events.csv` 追加 `transfer` 事件

## 维修资产

示例：

```text
资产编号 SY020101052405 今天开始维修，故障是无法开机，预计维修费 300 元，送联想售后，经办人王五。
```

我会执行：

- 根据你确认的口径更新 `资产现状` 或 `盘点情况`
- 在 `data/asset_events.csv` 追加 `repair_start` 事件

## 报废资产

示例：

```text
资产编号 SY020101052007 因主板损坏无法维修，资产现状改为待报废，审批单号 SCRAP-2026-001。
```

我会执行：

- 将 `资产现状` 更新为 `待报废`
- 在 `data/asset_events.csv` 追加 `dispose` 事件
- 不删除主档记录，保留历史可追溯

## 盘点资产

示例：

```text
盘点资产编号 SY020101052405，结果账实相符，盘点人张三，盘点日期 2026年7月24日。
```

我会执行：

- 更新 `盘点情况`
- 在 `data/asset_events.csv` 追加 `inventory_check` 事件

## 信息不完整时

如果缺少关键字段，我会优先根据 `资产编号` 定位资产；如果新增资产没有 `资产编号`，我会先向你确认编号规则，不擅自生成公司正式编号。
