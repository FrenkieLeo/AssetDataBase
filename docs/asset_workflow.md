# 资产管理流程

本项目的资产主档以 `data/assets.csv` 为准，字段完全沿用盘点册原表。所有资产变化都应同时保留事件流水，方便以后回溯。

## 1. 购置 / 补录

需要记录：

- 资产编号
- 资产名称
- 规格型号
- 资产类别
- 权属单位
- 现使用单位
- 购置日期
- 账面原值
- 账面净值
- 使用部门
- 存放地点
- 使用人
- 资产现状
- 原固定资产编码
- 盘点情况

维护动作：

1. 在 `data/assets.csv` 按原表 16 列新增资产主档。
2. `序号` 按当前最大序号顺延。
3. 在 `data/asset_events.csv` 追加 `purchase` 或 `register` 事件。

## 2. 领用 / 调拨

需要记录：

- 资产编号
- 原使用部门、原存放地点、原使用人
- 新使用部门、新存放地点、新使用人
- 调拨日期
- 经办人、审批或单据编号

维护动作：

1. 更新 `data/assets.csv` 中该资产的 `使用部门`、`存放地点`、`使用人`。
2. 如果实际使用单位变化，同时更新 `现使用单位`。
3. 在 `data/asset_events.csv` 追加 `assign` 或 `transfer` 事件。

## 3. 维修

需要记录：

- 资产编号
- 故障描述
- 维修开始日期、完成日期
- 维修费用、维修商或维修人
- 维修结果

维护动作：

1. 维修开始时，优先在 `盘点情况` 或事件备注中记录维修说明。
2. 如果公司台账确认使用维修状态，可将 `资产现状` 更新为统一约定的维修状态。
3. 在 `data/asset_events.csv` 追加 `repair_start` 或 `repair_done` 事件。

## 4. 盘点

需要记录：

- 盘点日期
- 盘点人
- 资产是否在账、在位、状态是否正常
- 差异说明

维护动作：

1. 更新 `data/assets.csv` 中该资产的 `盘点情况`。
2. 如果发现实际使用部门、存放地点、使用人或资产现状变化，同步更新主档对应字段。
3. 对所有关键资产或差异资产追加 `inventory_check` 事件。

## 5. 报废 / 处置

需要记录：

- 资产编号
- 报废原因
- 审批编号
- 处置收入或成本
- 处置日期

维护动作：

1. 将 `data/assets.csv` 中该资产 `资产现状` 更新为 `待报废` 或公司确认的最终状态。
2. 不删除主档记录。
3. 在 `data/asset_events.csv` 追加 `dispose` 事件。
