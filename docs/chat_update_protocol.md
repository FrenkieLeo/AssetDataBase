# 聊天维护约定

你之后可以直接用自然语言让我登记资产或变更资产。为了减少来回确认，建议尽量包含以下信息。

## 新增资产

示例：

```text
登记一台新电脑：ThinkPad X1 Carbon，联想，序列号 PF5XXXXX，2026-07-24 买的，8999 元，供应商京东自营，给研发部李四使用，地点上海办公室 B 区，保修到 2029-07-23。
```

我会执行：

- 分配新的 `asset_id`
- 写入 `data/assets.csv`
- 追加 `purchase` 事件到 `data/asset_events.csv`

## 调拨资产

示例：

```text
把 OA-2026-0001 从行政部张三调拨给研发部李四，地点从 A 区改到 B 区，经办人王五，今天生效。
```

我会执行：

- 更新资产主档当前部门、责任人、地点
- 追加 `transfer` 事件

## 维修资产

示例：

```text
OA-2026-0001 今天开始维修，屏幕损坏，预计费用 300 元，送到联想售后，经办人王五。
```

我会执行：

- 将资产状态改为 `repairing`
- 追加 `repair_start` 事件

## 报废资产

示例：

```text
OA-2026-0001 因主板损坏无法维修，今天报废，审批单号 SCRAP-2026-001。
```

我会执行：

- 将资产状态改为 `disposed`
- 追加 `dispose` 事件

## 信息不完整时

如果缺少关键字段，我会先登记为草稿或向你确认。关键字段通常包括：

- 新增资产：资产名称、类别、购置日期或登记日期、当前状态
- 资产变更：资产编号、事件类型、发生日期
