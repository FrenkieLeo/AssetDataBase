# 字段字典

## `data/assets.csv`

资产主档严格沿用《2026年办公类固定资产年度盘点册（0724）》的 16 个字段。

| 字段 | 必填 | 说明 | 示例 |
|---|---:|---|---|
| `序号` | 是 | 当前明细表内的顺序号；新增资产时顺延编号 | `419` |
| `资产编号` | 是 | 资产唯一编号，优先使用公司固定资产系统编号 | `SY020101052405` |
| `资产名称` | 是 | 资产名称，按原台账名称填写 | `台式电脑` |
| `规格型号` | 否 | 品牌、型号、配置或尺寸信息 | `联想 开天 M90h` |
| `资产类别` | 是 | 固定资产分类 | `计算机` |
| `权属单位` | 是 | 资产产权或账面归属单位 | `广州交投实业有限公司` |
| `现使用单位` | 是 | 当前实际使用单位 | `广州交投实业有限公司` |
| `购置日期` | 否 | 原表日期口径，统一保留为中文日期 | `2024年11月27日` |
| `账面原值` | 否 | 财务账面原值，单位默认为元 | `4787.61` |
| `账面净值` | 否 | 财务账面净值，单位默认为元 | `3067.44` |
| `使用部门` | 否 | 当前使用或管理部门 | `安全监管部` |
| `存放地点` | 否 | 当前所在办公室、房间、仓库或部门区域 | `安全监管部` |
| `使用人` | 否 | 当前使用人；如部门统一管理则保留原表写法 | `陈文初` |
| `资产现状` | 是 | 当前状态，现有枚举为 `在用`、`闲置`、`待报废` | `在用` |
| `原固定资产编码` | 否 | 历史固定资产编码或旧系统编码 | `SY225152` |
| `盘点情况` | 否 | 年度盘点结果、差异说明或核查备注 | `账实相符` |

## `data/asset_events.csv`

事件流水用于追踪资产主档发生过的变化，不改变主档必须遵循原盘点册字段的原则。

| 字段 | 必填 | 说明 | 示例 |
|---|---:|---|---|
| `event_id` | 是 | 事件唯一编号 | `EVT-20260724-0001` |
| `event_date` | 是 | 业务发生日期 | `2026-07-24` |
| `asset_id` | 是 | 对应 `资产编号` | `SY020101052405` |
| `event_type` | 是 | 事件类型 | `transfer` |
| `from_department` | 否 | 原使用部门 | `综合管理部` |
| `to_department` | 否 | 新使用部门 | `财务部` |
| `from_owner` | 否 | 原使用人 | `张三` |
| `to_owner` | 否 | 新使用人 | `李四` |
| `from_location` | 否 | 原存放地点 | `9楼文印室` |
| `to_location` | 否 | 新存放地点 | `财务部` |
| `amount` | 否 | 涉及金额，如原值、维修费、处置收入 | `300` |
| `currency` | 否 | 币种，默认 `CNY` | `CNY` |
| `handler` | 否 | 经办人 | `行政专员` |
| `document_ref` | 否 | 单据、合同、发票、审批或旧资产编码 | `BGSB-201612-040` |
| `notes` | 否 | 备注 | `根据年度盘点册补录` |
| `created_at` | 是 | 记录创建时间 | `2026-07-24 10:30` |

## 事件类型

| `event_type` | 含义 |
|---|---|
| `register` | 补录历史资产 |
| `purchase` | 新购置 |
| `stock_in` | 入库 |
| `assign` | 领用/分配 |
| `transfer` | 调拨 |
| `repair_start` | 开始维修 |
| `repair_done` | 维修完成 |
| `inventory_check` | 盘点 |
| `loss` | 遗失 |
| `dispose` | 报废/处置 |
